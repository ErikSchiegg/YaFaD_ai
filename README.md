# YaFaD_ai
YaFaD_ai: Bio-inspired high-performance middleware. Uses an AI-driven Utility Index (pheromone principle) and cascading sub-tables via Golden Ratio to predictively accelerate data access. Hybrid Go/Rust core for maximum AI-era efficiency. Forgets the trivial, prioritizes the relevant.

## The "Forgetfulness" Logic (Decay)
YaFaD stays fast by mimicking biological memory. Every record's relevance decays over time unless reinforced by activity:

$$U_{now} = U_{last} \cdot e^{-\lambda \cdot \Delta t}$$

* $U$: Utility Index
* $\lambda$: Decay constant (The "Administrator Factor")
* $\Delta t$: Time since last access
